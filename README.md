# Hardware Saber Builder

A 3D interactive builder for hardware sabers, built with React Three Fiber and Vite.

## Features

- 3D saber customization
- Interactive component selection
- Real-time preview
- Export to PDF

## Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Technologies

- **React** - UI framework
- **React Three Fiber** - 3D rendering
- **Three.js** - 3D graphics
- **Vite** - Build tool
- **Zustand** - State management
- **jsPDF** - PDF export
